About Me

A Computer Science student and web developer in Peshawar, learning through real projects, disciplined practice, and honest problem-solving.

Hi, I'm Afaq Ahmad

I'm an FSc Computer Science student at The Superior Group of Colleges and a web development student at SMIT in Peshawar, Pakistan. I build responsive, functional websites with HTML, CSS, and vanilla JavaScript while actively expanding into backend development.

My path into programming began in April 2026 when I enrolled in the Web & App Development program at Saylani Mass IT Training (SMIT). I didn't come from a tech background, and at first, I didn't even have a laptop. I wrote my first HTML and CSS exercises on an Android phone, testing syntax on mobile code editors and working through village internet connectivity issues. After several months of steady practice, I was able to buy my first laptop—which opened up real developer tools, browser inspection, and local workflows.

My progress has come from building real websites, running into bugs, and working through them until things work properly. My first client project was a responsive product showcase for Blue Sapphire Gem Stones, an active gemstone business. That project taught me what it actually takes to organize product specifications, build responsive image-heavy cards, and communicate with an actual business owner. Alongside client work, I build focused practice projects to master responsive layouts, CSS Grid, and core JavaScript logic.

Right now, I am deepening my JavaScript foundations while learning Node.js, Express, and database basics at SMIT. My longer-term goal is to pursue university studies in Computer Science, continue building useful software, and grow into a capable, thoughtful full-stack engineer.

What I Stand For

Personal Values

Continuous Learning

Fundamentals endure. Investing time in core concepts—semantic markup, CSS layout models, and JavaScript execution—builds lasting ability.

Readable Structure

Code is read and debugged more often than it is written. Clear naming, structured markup, and organized stylesheets make collaboration painless.

Accessible by Default

Websites should work for real people on various devices, screen sizes, and connection speeds. Proper semantic structure is the baseline requirement.

Performance & Restraint

No artificial delays, no heavy background loops that drain mobile batteries. Clean, lightweight code respects the user's device and time.

Problem Solving

Getting stuck is part of the work. Real learning happens when you inspect the DOM, read documentation, isolate variables, and fix the root cause.

Real-World Utility

A website exists to serve a purpose—whether explaining a service, displaying products, or answering questions. Clarity always comes first.
